# 11/16 PPT 이미지·영상 삽입안

발표 범위는 지난 UWB–ESP32 통신 확인 이후 Raspberry Pi 수신·저장과 경량 UI까지입니다. 기존 전체 UI·배터리 트리거·층별 확장을 이번 구현 결과에 넣지 않습니다.

각 이미지의 발표 문장은 [단계별 설명 자료](단계별_설명자료.md)를 사용합니다. 네 장을 같은 크기·같은 위치로 배치하고 화면 전환은 단순 전환으로 맞춥니다. 생성 이미지는 아이보리 배경·검은 손글씨와 펜 선·하늘색 강조를 공통으로 사용하며, 모든 PNG는 [이미지 저장 폴더](../이미지%20저장/_이미지_목록.md)에 모았습니다.

## 구성도에서 설명할 순서

1. **중앙 Pi와 A0**: Pi의 USB 3.0 포트와 A0 ESP32를 USB 케이블로 연결합니다. Pi GPIO에 UWB를 직접 연결한 구조가 아닙니다.
2. **양옆 A1·A2**: ESP32+DWM3000EVB 앵커가 측정 보고를 ESP-NOW로 A0에 전달합니다.
3. **Tag와 세 앵커**: UWB로 거리를 측정합니다. 공유기 Wi-Fi로 Tag의 거리를 재는 방식이 아닙니다.
4. **Pi 내부 처리**: A0의 USB 시리얼을 읽어 위치를 계산하고 SQLite에 저장한 뒤 웹 화면에 표시합니다.
5. **화면 접속**: 같은 Wi-Fi의 Mac·휴대폰에서 Pi에 HTTP로 접속합니다.

그림 아래 넣을 짧은 설명:

> UWB로 거리 측정 → ESP-NOW로 A0에 보고 → USB로 Pi에 전달 → 경량 화면에 표시

## 그림의 사용 범위

- 구성도는 사용자가 요청한 단순한 실내 배치 예시입니다. 실제 교실 사진이나 실측 좌표 도면으로 소개하지 않습니다.
- A1·A2는 실제 배치가 달라질 수 있습니다. 마지막 시험의 교정 거리는 A0–A1 6.894 m, A0–A2 6.569 m, A1–A2 3.471 m입니다.
- 시험마다 앵커 번호·배치·상호 거리를 확인하고, 이동 후에는 다시 교정합니다.
- 교정의 반복 측정 산포 약 8 cm를 위치 정확도 8 cm라고 발표하지 않습니다.
- 프레젠테이션에서 실제 UI와 실제 영상은 원본 파일을 사용합니다. 그림 생성으로 시험 결과를 대신하지 않습니다.

## PPT 편집 시 확인

- 16:9 슬라이드에 그림 전체가 보이도록 삽입하고 비율을 잠급니다. 그림의 선이나 라벨이 잘리도록 채우기 자르기를 하지 않습니다.
- 생성 이미지에 제목이 있으므로 같은 제목을 슬라이드에 중복해서 넣지 않습니다.
- 영상은 `삽입 → 비디오 → 파일에서` 방식으로 넣고, 발표할 PC에서 오프라인 재생을 확인합니다.
- 발표 폴더의 MD·PNG·MP4는 구성 자료입니다. 이 문서는 PPT 삽입 설계안이며 완성된 PPTX 파일은 아닙니다.
